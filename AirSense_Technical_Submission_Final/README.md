# AirSense — Final Technical Submission Package

## 1. Project
**Advanced IoT-Based Particulate Matter and Air Quality Monitoring System Using ESP32 with Real-Time Analytics**

## 2. Problem and objective
The system demonstrates an end-to-end embedded IoT pipeline for environmental monitoring: DHT11 acquisition → ESP32 processing → local OLED display → Wi-Fi/HTTPS → Firebase Realtime Database → mobile visualization and analytics.

## 3. Implemented hardware
- ESP32 DevKit V1
- DHT11 temperature/humidity sensor
- SSD1306 128×64 I²C OLED
- Breadboard, jumper wires and USB power
- DHT11 DATA → GPIO 4
- OLED SDA → GPIO 21
- OLED SCL → GPIO 22
- OLED I²C address → 0x3C
- Supply → USB / 5V input

**PM2.5 status:** The current firmware generates PM2.5 programmatically for development/testing. A physical GP2Y1014 channel is referenced in the mobile diagnostics, but the exported PM2.5 values in this submission are not claimed as calibrated physical particulate measurements.

## 4. Software
### ESP32
Arduino/C++ firmware using:

### Mobile
Flutter/Dart application using:
- Flutter
- firebase_core
- firebase_database

## 5. Data flow
1. DHT11 is sampled by the ESP32.
2. PM2.5 is generated by the firmware simulation.
3. Status is classified from PM2.5 thresholds.
4. OLED is refreshed locally.
5. `/sensor` is updated with the latest JSON payload.
6. `/readings` receives a historical JSON record.
7. Flutter reads `/sensor` for live display and `/readings` for historical analytics.

## 6. Reproduction
1. Install Arduino IDE and ESP32 board support.
2. Install the listed Arduino libraries.
3. Open `source_code/esp32/EXP8_submission.ino`.
4. Replace `YOUR_WIFI_SSID` and `YOUR_WIFI_PASSWORD`.
5. Select the ESP32 board and correct serial port.
6. Upload firmware.
7. Open Serial Monitor at 115200 baud.
8. Confirm DHT11 readings, PM2.5 simulation and Firebase HTTP responses.
9. Open the Flutter project in `source_code/mobile_app`.
10. Run `flutter pub get`.
11. Configure Firebase project credentials if the evaluator uses a different Firebase project.
12. Run the Android application and verify live/history screens.
